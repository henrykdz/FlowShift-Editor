## 🚀 Introduction

**FlowShift** is a sovereign document workbench that unifies **Markdown**, **HTML/CSS**, and **YAML** into a single, cohesive 1:1 layout workflow.

> Built for professionals who demand absolute control over content, form, and geometry.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| **Flicker‑free live rendering** | Real-time preview via `Sovereign Swap` |
| **Auto-Focus Navigation** | Click in preview → jump to source |
| **Diagnostic Linter** | Real-time structural validation |
| **CSS Design Forge** | Live styling in the document flow |
| **1:1 Precision Slicer** | 3.78 px/mm geometry for pixel-perfect output |
| **Smart Formatter** | One-click Auto-Fix for Markdown, HTML, CSS |
| **Custom Placeholders** | YAML-based data injection |

## 🏗️ Architecture

- **JavaFX Desktop Application** – Native performance  
- **Hybrid Rendering Engine** – Markdown → HTML → WebView  
- **Real-time Source Mapping** – Click, edit, preview  
- **Modular Design** – Clean separation of concerns

<details>
<summary><b>🔧 Technology Stack</b></summary>

| Component | Technology |
|-----------|------------|
| Java | JavaSE-26 (Zulu) + JavaFX 25 |

| Markdown | Flexmark-Java v0.64.8 |

| Icons | Ikonli v12.4.0 |
